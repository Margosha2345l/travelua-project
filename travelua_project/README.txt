TravelUA — готовий навчальний проєкт для теми
«Сайт для бронювання турів (туристична агенція)».

Що зробити перед здачею:
1. Відкрийте файли та замініть [Ваше ПІБ] і [Ваша група].
2. Запустіть index.html у браузері.
3. Для демонстрації перейдіть на сторінку tours.html.
4. Натисніть «Забронювати», оберіть дату і кількість осіб.
5. Натисніть «Розрахувати вартість».

Структура:
- index.html
- tours.html
- about.html
- contacts.html
- css/style.css
- js/script.js
- images/*.svg

Проєкт працює локально без сервера.
